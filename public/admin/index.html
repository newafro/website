NewAfro Editor

Editor mode

This is the content manager for newafro.net. Once GitHub OAuth is connected, editors can sign in here and edit blog posts and pages through a WYSIWYG — no git knowledge required.

Setup (one-time, ~10 min):

  1. On GitHub: Settings → Developer settings → OAuth Apps → New OAuth App. Callback URL https://newafro.net/admin/.
  2. Deploy a tiny OAuth proxy (Cloudflare Worker recipe in 04-deploy-admin/setup-decap-oauth.md) and paste its URL into public/admin/config.yml.
  3. Add editors as repo collaborators (write access on Kisgus/newafro).

Full step-by-step in setup-decap-oauth.md.

Until OAuth is configured, clicking "Login with GitHub" below will fail — that's expected. Everything else on the site ( homepage, journal, events, community) is fully working.
